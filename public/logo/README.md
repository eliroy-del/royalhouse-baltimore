# Royalhouse logo

The official Royalhouse Chapel mark is stored here as `royalhouse-chapel.png`.

It was copied from the supplied artwork. Nothing in this project redesigns,
recolours, crops, or approximates the crown, dove, chevron or wordmark.

The dove is white, so the native white field is preserved. On navy surfaces
the mark sits in a white rounded badge (a container, not an edit). Sizing
is CSS-only; the 1:1 aspect ratio is locked.

To replace the file, drop a higher-resolution official PNG or SVG of the
same artwork here and update the `width` / `height` in `src/config/brand.ts`.
No other change is required.
